# FollowUser — plugin Enmity

Suit automatiquement un utilisateur dans les salons vocaux Discord (iOS, Enmity) : quand il rejoint ou change de salon, tu le rejoins.

## Installation

Enmity > Paramètres > Plugins > **+**, puis colle ce lien :

```
https://raw.githubusercontent.com/NANODLAPISCINE/folowenmity/main/FollowUser.js
```

## Utilisation

- `/follow <utilisateur>` : commence à suivre quelqu'un
- `/unfollow` : arrête de suivre

Options dans les paramètres du plugin : rejoindre immédiatement, quitter le vocal quand il part, suivre seulement si tu es déjà en vocal, notifications.
